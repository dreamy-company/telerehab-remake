Platform TeleRehab – Diagram Arsitektur Sistem

Dokumentasi sistem platform telerehabilitasi yang dibangun dengan Laravel 12 + Livewire 3. Mencakup dua antarmuka: aplikasi web (Livewire) dan REST API untuk aplikasi mobile pasien (Sanctum). Termasuk fitur baru Pelacakan Gerakan Real-time menggunakan MediaPipe Pose Landmarker.

4 Peran: Admin · Dokter · Terapis · Pasien Web (Livewire) + API Mobile (Sanctum) Pelacakan Gerakan Real-time (MediaPipe + Pusher) 10 Entitas Utama Database
👤
Diagram Use Case
Empat aktor berinteraksi dengan Sistem TeleRehab: Admin, Dokter, Terapis, dan Pasien. Sistem mengirimkan notifikasi email melalui Server Email eksternal dan menyiarkan kejadian real-time melalui Server Pusher. Pasien adalah aktor utama untuk fitur baru Pelacakan Gerakan Real-time menggunakan MediaPipe di sisi browser.
